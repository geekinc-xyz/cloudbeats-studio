========================================================================
STUDIO DE MUSIQUE - DOSSIER D'ÉCHANTILLONS DE XYLOPHONE (.WAV / .MP3)
========================================================================

Vous pouvez déposer vos propres fichiers audio (.wav ou .mp3) dans ce dossier.

Noms de fichiers recommandés pour les lames du Xylophone (Notes Do4 à Do6) :
- c4.wav  / c4.mp3  (Do 4)
- d4.wav  / d4.mp3  (Ré 4)
- e4.wav  / e4.mp3  (Mi 4)
- f4.wav  / f4.mp3  (Fa 4)
- g4.wav  / g4.mp3  (Sol 4)
- a4.wav  / a4.mp3  (La 4)
- b4.wav  / b4.mp3  (Si 4)
- c5.wav  / c5.mp3  (Do 5)
- d5.wav  / d5.mp3  (Ré 5)
- e5.wav  / e5.mp3  (Mi 5)
- f5.wav  / f5.mp3  (Fa 5)
- g5.wav  / g5.mp3  (Sol 5)
- a5.wav  / a5.mp3  (La 5)
- b5.wav  / b5.mp3  (Si 5)
- c6.wav  / c6.mp3  (Do 6)

Note : L'application génère automatiquement des sonorités réalistes de xylophone
si aucun fichier n'est présent dans ce dossier, ou vous permet de glisser-déposer
vos propres fichiers audio via l'interface web.
