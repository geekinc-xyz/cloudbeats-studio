========================================================================
STUDIO DE MUSIQUE - DOSSIER D'ÉCHANTILLONS DE BATTERIE (.WAV / .MP3)
========================================================================

Vous pouvez déposer vos propres fichiers audio (.wav ou .mp3) dans ce dossier.

Noms de fichiers recommandés pour un chargement automatique :
- kick.wav  ou  kick.mp3     (Grosse Caisse)
- snare.wav ou  snare.mp3    (Caisse Claire)
- hihat.wav ou  hihat.mp3    (Charley Fermé)
- openhat.wav ou openhat.mp3 (Charley Ouvert)
- tom1.wav  ou  tom1.mp3     (Tom Aigu / Mid)
- tom2.wav  ou  tom2.mp3     (Tom Basse)
- crash.wav ou  crash.mp3    (Cymbale Crash)
- ride.wav  ou  ride.mp3     (Cymbale Ride)
- clap.wav  ou  clap.mp3     (Clap / Percussion)

Note : Vous pouvez aussi importer directement n'importe quel fichier .wav / .mp3
depuis l'interface web de l'application dans la section "Gestionnaire d'échantillons".
